| **三級分** | 三級分的文章在表達上是不充分的，這種文章明顯具有下列特徵： | 嘗試依據題目或寫作任務，統整、運用材料，但不甚適當，或發展不夠充分。 | 文章結構鬆散；或前後不連貫。 | 用字遣詞不太恰當，或出現錯誤；或冗詞贅句過多。 | 有一些錯別字，及格式、標點符號運用上的錯誤，以致造成理解上的困難。 |
| **二級分** | 二級分的文章在表達上呈現嚴重的問題，這種文章明顯具有下列特徵： | 雖嘗試依據題目或寫作任務，統整、運用材料，但有所不足，或大量引述題幹內容，發展有限。 | 文章結構不完整；或僅有單一段落，但可區分出結構。 | 遣詞造句常有錯誤。 | 不太能掌握格式，不太會使用標點符號，錯別字頗多。 |
| **一級分** | 一級分的文章在表達上呈現極嚴重的問題，這種文章明顯具有下列特徵： | 僅解釋題目或題幹內容；或雖提及主題，但材料過於簡略或無法選取相關材料加以發展。 | 沒有明顯的文章結構；或僅有單一段落，且不能辨認出結構。 | 用字遣詞極不恰當，頗多錯誤；或文句支離破碎，難以理解。 | 不能掌握格式，不會運用標點符號，錯別字極多。 |
| **零級分** | 不予給分 | 完全離題、只訂題目、僅抄寫題目或題幹內容、使用詩歌體、空白卷。 | | | |

## 三、 四大評分向度之級分換算與權重體系

在會考實務批閱中，各向度並非簡單算術平均，而是以**「立意取材」作為評分靈魂與級分上限**：
1. **立意取材上限法則**：
   - 若立意取材判定為 3 級分，則該篇作文之最終總體級分**最高不得超過 3 級分**（縱使修辭優美或無錯字，亦不得破格晉升）。
   - 若立意取材判定為 4 級分，則最終總體級分原則上為 4 級分，除非結構與文采極為卓越且篇幅充足方得爭取 5 級分。
2. **遣詞與錯字之扣分調節**：
   - 錯別字每滿 3 個不同錯字，通常在級分邊界（如 4 級分臨界 5 級分）造成降級影響。
   - 全篇「一逗到底」（整段或整篇無句號）者，結構與標點向度直接降為 3 級分以下。
